# Battery Voltage Monitor

## Overview
The Battery Voltage Monitor is a simple and effective system designed to monitor battery voltage levels using an LM339 comparator IC.

The system uses LEDs to indicate different voltage levels of the battery.

## Objectives
- Monitor battery voltage levels
- Prevent overcharging and deep discharge
- Provide real-time voltage indication
- Develop a low-cost monitoring system

## Components Used
- LM339 Comparator IC
- 100kΩ Variable Resistor
- 1kΩ Resistors
- LEDs
- 12V Battery
- Breadboard
- Connecting Wires

## Working Principle
The LM339 comparator compares the battery voltage with preset reference voltages.

When voltage reaches a threshold:
- LEDs glow according to voltage level
- Different LEDs indicate battery condition

## Applications
- UPS Systems
- Solar Battery Systems
- Automotive Batteries
- Renewable Energy Applications
